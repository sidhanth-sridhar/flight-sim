  THE PHASE, IN ORDER (§14). The jet is deliberately LAST.

  1. WIND. At minimum a wind LAYER that changes with altitude — one wind at
     the surface and another aloft is what makes a real circuit different
     from a still-air one, and it makes crosswind landings exist by
     construction, which is the highest-value skill this game can teach.
     FlightModel's relative-wind model already acts on the air, so wind is a
     field added to it rather than new physics.
  2. TURBULENCE. A gust model on the standard — Dryden or Von Kármán spectra,
     per MIL-F-8785C / MIL-HDBK-1797 — driving gust velocities the aircraft's
     own stability damps, as a real pilot damps them. Tuning rule: persistent
     enough to feel like rough air, mild enough that a trimmed aeroplane still
     holds its trim. ⚠️ SEED-DETERMINISTIC: the same seed must reproduce the
     same flight, or none of it is assertable. ⚠️ §6i's peak-capture lesson
     applies — gusts act between physics frames, so any instrument fed by them
     needs the same treatment §15 proved necessary for alpha.
  3. WIND SHEAR / THE MICROBURST. Low-level shear is the deadliest weather
     near the ground; the canonical case is the burst ~150 ft AGL on a 90 kt
     approach, where the loss of headwind is answered by a downdraft. THIS IS
     THE PHASE'S GATE and the reason weather is not decorative. It must be
     SURVIVABLE BUT HARD — if it is not both, the numbers are wrong.
  4. TEMPERATURE AND QNH AS WEATHER INPUTS. Atmosphere already takes
     tempOffsetC and qnhPa — ISA deviation for hot-day performance, and the
     pressure setting an altimeter reads. Phase 5 wires these to selectable
     presets rather than constants, and §32's instrument-error mechanism
     becomes visible for the first time.
  5. THE JET — LAST, and not because it is small. Aircraft/Registry.luau is
     already id → definition and is the only thing crossing the network at
     spawn, so the jet proves the registry generalises, and it is where the
     compressibility correction Atmosphere notes for "the Phase 5 jet"
     finally gets exercised. It is the RISK: a second aircraft touches every
     assumption the first one made.

  HOW TO TEST IT
  Wind and gusts are deterministic fields given a seed, so the same seed must
  reproduce the same flight — assertable in the existing pure-function style.
  The shear gate is a scenario scripted to the canonical numbers (headwind
  loss, downdraft, height above threshold), flown on instruments. Assert
  against published figures and standards, not against what the code does.

  GATE: the pilot flies a crosswind landing, and flies the wind-shear
  scenario. The microburst must be survivable but hard.
